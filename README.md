The Meridian Job — a top-down heist game. One bank, three rooms, one diamond. Cross the Lobby, the Gallery and the Vault unseen: guards walk patrols with vision cones, cameras sweep the floor, and the alarm meter fills whenever you are seen. Take the loot in each room, then reach the van door. Tools cost you: an EMP kills a camera for a few seconds (two charges a room), a smoke bomb hides you where you stand (one a room), and a lockpick opens a shortcut if you can stand still for two seconds beside a locked door. All art is procedural canvas drawing, all sound is procedural WebAudio — no assets, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD or arrows to move, Shift to sneak, 1 for EMP, 3 for smoke, E to pick a lock, Esc to pause, M to mute.
